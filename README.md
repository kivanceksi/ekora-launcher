# Ekora Launcher

Windows launcher and Turkish per-user installer for EkoraMC.

The Windows workflow builds the standalone application and Setup.exe, installs it, verifies the desktop shortcut and packaged UI, and checks uninstall. Build artifacts are private until deliberately published.

Current scope: local username profiles, Minecraft/Java installation, Quick Play to play.ekoramc.fun, Turkish interface, local settings, managed-mod checks and optional server status API. Server-side account authentication remains separate.

The installer is unsigned unless a release signing process is configured. Minecraft gameplay and server integration require separate end-to-end validation.

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
